Variables y tipos: guardar datos con un nombre

Abri la consola del navegador con F12 antes de empezar, y dejala abierta toda la clase. Ahi el navegador te explica que salio mal.

1. Donde vive el JavaScript

<script> ... aca va el codigo ... </script>

La etiqueta <script> va al final del body, despues de todo el HTML. Si la pones arriba, el JavaScript busca elementos que todavia no existen y tira Cannot read properties of null.

console.log() escribe en la consola, no en la pagina. Es tu herramienta numero uno.

2. let y const

let puntos = 0;      // va a cambiar
const nombre = "Ana"; // no va a cambiar

Una variable es una caja con nombre. Usa let cuando el valor va a cambiar y const cuando no. Regla practica: arranca siempre con const, y si el navegador se queja porque necesitas reasignar, recien ahi pasalo a let.

3. Los tres tipos que importan hoy

const texto = "Ana";    // string, entre comillas
const precio = 290000;  // number, sin comillas
const activo = true;    // boolean, true o false

La diferencia se ve con typeof. Ojo con "290000" entre comillas: parece un numero pero es texto, y con texto no se puede hacer cuentas.

4. Pegar textos con +

"Hola " + nombre + ", tenes " + edad + " años"

El signo + entre textos los pega uno atras del otro. Cuidado con los espacios: van adentro de las comillas, si no las palabras quedan juntas.

5. El error mas comun de toda la clase

campoA.value + campoB.value  // "1050" <- pego los textos
Number(campoA.value) + Number(campoB.value)  // 60 <- ahora suma

Todo lo que sale de un input es texto, incluso cuando el campo dice type="number". Para hacer cuentas hay que convertirlo con Number(). Proba los dos botones y mira la diferencia.

Cuando algo no funcione, la primera pregunta es siempre la misma: ¿que dice la consola?
