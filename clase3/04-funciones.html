Funciones: escribirlo una vez y usarlo siempre

Una funcion es una receta con nombre. Se escribe una vez y se usa las veces que haga falta.

1. Declarar y llamar

function saludar(nombre) { // el molde return "Hola " + nombre; } saludar("Ana"); // la llamada

El parentesis de arriba es el molde: dice que datos espera. El de abajo son los datos reales. La funcion no hace nada hasta que la llamas.

2. return devuelve, console.log solo muestra

function calcularIva(monto) { console.log(monto * 0.10); // muestra y se olvida } const iva = calcularIva(100000); // iva queda undefined
function calcularIva(monto) { return monto * 0.10; // entrega el valor } const iva = calcularIva(100000); // iva vale 10000

return hace dos cosas: entrega el valor a quien llamo la funcion y corta la ejecucion ahi mismo. Sin return, la funcion devuelve undefined.

3. Llamar sin parentesis no ejecuta nada

calcularIva    // muestra la funcion
calcularIva(100000) // la ejecuta

Abri la consola (F12) y apreta el boton: vas a ver las dos cosas una debajo de la otra.

4. El descuento del bloque 2, ahora como funcion

En el archivo anterior el calculo del descuento estaba suelto dentro del boton. Si lo necesitamos en otro lugar hay que copiarlo, y si cambia un tramo hay que acordarse de cambiarlo en los dos lados. Codigo repetido = funcion.

function calcularDescuento(monto) { if (monto >= 2000000) return 10; if (monto >= 500000) return 5; return 0; }

Fijate que aca no hace falta else: como return corta la funcion, si entro por el primero nunca llega al segundo.

5. Combinar funciones

Cada funcion hace una cosa sola, y despues se usan juntas. Estas dos son de la vida real paraguaya: el IVA del 10% y la conversion a dolares.

6. Alcance: lo de adentro se queda adentro

function calcular() { const resultado = 5 * 3; } console.log(resultado); // Error: resultado is not defined

Lo que se declara dentro de una funcion existe solo ahi. Si lo necesitas afuera, la funcion tiene que return-earlo.

Una funcion bien hecha se entiende por el nombre sin leer el cuerpo. Si no sabes como llamarla, probablemente hace demasiadas cosas.
