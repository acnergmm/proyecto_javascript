Arrays: muchos datos con un solo nombre

Cuatro precios se pueden guardar en cuatro variables. Cuarenta, no. Para eso esta el array: una caja con muchos compartimentos numerados.

1. Crear y leer por indice

const precios = [290000, 75000, 2200000, 440000];
[0]290000
[1]75000
[2]2200000
[3]440000

Se cuenta desde cero. El primero es precios[0] y el ultimo es precios[precios.length - 1]. length dice cuantos hay.

precios[4]  // undefined: ese compartimento no existe
precios[precios.length - 1] // el ultimo, siempre

2. Agregar, sacar y buscar

productos.push("Webcam");  // agrega al final productos.pop();          // saca el ultimo productos.includes("Mouse"); // true o false

Fijate que el array se declara con const y aun asi se le pueden agregar cosas: lo que no se puede es reemplazar el array entero por otro.

3. Array + ciclo: el total

let total = 0; // afuera del ciclo for (let i = 0; i < precios.length; i++) { total = total + precios[i]; // se actualiza adentro }

Este esqueleto es el mas usado de la clase: variable afuera, ciclo, actualizar adentro. Si la declaras adentro, se reinicia en cada vuelta y el total sale mal.

4. Array + ciclo: el mas caro

Mismo esqueleto, pero en vez de sumar comparamos. Arrancamos suponiendo que el primero es el mayor, y cada vez que encontramos uno mas grande lo reemplazamos.

let mayor = precios[0]; for (let i = 1; i < precios.length; i++) { if (precios[i] > mayor) { mayor = precios[i]; } }

5. Dos arrays en paralelo

Los nombres en un array y los precios en otro, en el mismo orden: el nombres[i] corresponde al precios[i]. Es la forma mas simple de armar un catalogo antes de aprender objetos.

Cuando algo sale undefined con arrays, el 90% de las veces es un indice de mas: acordate que el ultimo es length - 1.
