Decisiones: que hago si pasa esto

Hasta ahora el codigo hacia siempre lo mismo. Con if empieza a elegir.

1. if / else

if (edad >= 18) { // camino A } else { // camino B }

Se lee tal cual suena: si la edad es mayor o igual a 18, hace lo primero; si no, hace lo segundo. Lo que va entre parentesis tiene que dar verdadero o falso.

2. Los comparadores

Se escribeSignifica
a > ba es mayor que b
a < ba es menor que b
a >= bmayor o igual
a <= bmenor o igual
a === bcompara si son iguales
a !== bcompara si son distintos
if (edad = 18)  // GUARDA 18 y da siempre verdadero
if (edad === 18) // COMPARA, que es lo que queriamos

Un solo = guarda un valor. Tres === comparan. Cuando todos los casos entran por la misma rama, el error es casi siempre este.

3. Mas de dos caminos: else if

if (monto >= 2000000) { descuento = 10; } else if (monto >= 500000) { descuento = 5; } else { descuento = 0; }

El orden importa. Gana la primera condicion que se cumple y las demas ni se miran. Si arrancamos por monto >= 500000, un monto de tres millones tambien cumple esa condicion y se lleva 5% en vez de 10%. Por eso van del tramo mas alto al mas bajo.

4. Combinar condiciones: &&, || y !

Se escribeEs verdadero cuando
a && bse cumplen las dos
a || bse cumple alguna
!aa es falso (lo da vuelta)

Truco para leer un if largo: leelo en voz alta en castellano. Si no se entiende dicho, tampoco se va a entender dentro de una semana.
