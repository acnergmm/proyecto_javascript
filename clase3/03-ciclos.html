Ciclos: hacer cien veces lo mismo sin escribirlo cien veces

Todo lo de hoy se puede hacer copiando y pegando. La pregunta es que pasa cuando son mil.

1. El for y sus tres partes

for (let i = 1; i <= 10; i++) { console.log(i); }
let i = 1donde arranca
i <= 10hasta cuando
i++como avanza

Esas tres partes van siempre, en ese orden, separadas por punto y coma. i++ es la forma corta de i = i + 1.

2. La tabla de multiplicar

A mano son diez lineas casi identicas. Con un for son tres, y sirve para cualquier numero.

3. El plan de cuotas

Esto va derecho a la calculadora del final de la clase: un monto, una cantidad de cuotas, y el detalle cuota por cuota.

4. while: cuando no sabes cuantas vueltas son

let saldo = 1000000; while (saldo > 0) { saldo = saldo - 250000; }

El for se usa cuando sabes la cantidad de vueltas; el while cuando la condicion depende de otra cosa. Aca vamos descontando hasta que el saldo se termine, sin saber de antemano cuantas veces va a ser.

while (saldo > 0) { }  // sin cambiar el saldo -> ciclo infinito, pestaña colgada

5. for...of: recorrer sin llevar la cuenta

for (const letra of "Paraguay") { console.log(letra); }

Cuando lo unico que queres es pasar por todos los elementos y no te importa el numero de vuelta, for...of es mas corto y se lee mejor. En la clase que viene lo vamos a usar sobre listas.

Si la pestaña se congela, es un ciclo infinito: cerrala y revisa que la variable del while cambie adentro del ciclo.
