Ejercicios — Clase 4

Regla general: usa siempre const o let, arrow functions, template literals y addEventListener. Nada de var ni de onclick dentro del HTML.

1. Contador de clicks

Cada click al boton sube el numero de a uno. El boton "Reiniciar" lo vuelve a cero.

  • El numero se muestra con un template literal, no concatenando con +.
  • Cuando llega a 10, mostrar un mensaje con SweetAlert2.

Pista: la variable del contador va con let y fuera de la funcion.

0

2. Lista de invitados

Al escribir un nombre y apretar Agregar (o Enter), se suma un <li> a la lista.

  • No se puede agregar vacio: avisar con SweetAlert2.
  • Cada invitado tiene un icono de persona de Font Awesome a la izquierda.
  • Mostrar siempre cuantos invitados hay.
  • Cada invitado tiene un boton de tacho que lo borra, pidiendo confirmacion.

Pista: createElement + append. Para contar, querySelectorAll(...).length.

    3. Semaforo con classList

    Tres botones que pintan el circulo. Obligatorio usar classList, prohibido usar .style.

    • Crear las clases .rojo, .amarillo y .verde en el CSS.
    • Antes de poner la clase nueva hay que sacar las otras dos.
    • Agregarle una animacion de Animate.css al cambiar.

    Pista: guarda los tres nombres en un array y usa forEach para sacarlos todos de una.

    4. Catalogo de productos (el importante)

    Te doy los datos ya escritos. Tenes que dibujar el catalogo en la pagina usando map, template literals e innerHTML.

    const productos = [
      { nombre: "Notebook", precio: 850000, stock: true },
      { nombre: "Tablet", precio: 320000, stock: false },
      { nombre: "Auriculares", precio: 45000, stock: true },
      { nombre: "Parlante", precio: 68000, stock: true }
    ];
    • Cada producto es una tarjeta con nombre, precio e icono.
    • Los que no tienen stock se ven grises (con una clase, no con style).
    • Abajo mostrar el total del catalogo, sumando con forEach.
    • Un boton "Ver solo disponibles" que filtre con filter.

    Desafio opcional — Separar en archivos

    Este archivo tiene todo adentro: HTML, CSS y JS mezclados. Reorganizalo como vimos hoy:

    ejercicios/
    ├── index.html
    ├── css/
    │   └── estilos.css
    └── js/
        └── app.js

    El index.html no puede quedar con ni un <style>, ni una linea de JavaScript, ni un onclick. Vinculalo todo con <link> y <script src="..." defer>.
