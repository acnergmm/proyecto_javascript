Fabricar HTML que no existia

Forma A: createElement (elemento por elemento)

Tres pasos siempre: crear con createElement, llenar con textContent, colgar con append. Si falta el tercero, el elemento existe pero no se ve.

    Forma B: template literals + innerHTML (bloques grandes)

    Cuando hay que armar mucho HTML de golpe, es mas comodo escribirlo como texto en varias lineas con backticks. Ideal para listados que vienen de datos.
