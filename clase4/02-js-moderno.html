JavaScript moderno: lo mismo, escrito mejor

Todo lo de abajo ya lo saben hacer. Lo que cambia es como se escribe hoy.

1. const y let (chau var)

var nombre = "Ana";  // forma vieja, evitar
const nombre = "Ana"; // nunca va a cambiar
let edad = 25;      // si va a cambiar

Regla practica: arranca siempre con const. Si el editor o el navegador se queja porque necesitas reasignarla, recien ahi la pasas a let. var no se usa mas.

2. Template literals: se terminaron los +

"Hola " + nombre + ", tenes " + edad + " años"
`Hola ${nombre}, tenes ${edad} años`

Se usan comillas invertidas (backtick, la tecla al lado del 1 o de la P segun el teclado) y cada variable va dentro de ${...}. Ademas permiten escribir en varias lineas.

3. Arrow functions

function sumar(a, b) {
    return a + b;
}
const sumar = (a, b) => a + b;

Si el cuerpo es una sola linea que devuelve algo, no hacen falta ni las llaves ni el return. Se usan muchisimo dentro de addEventListener.

4. forEach: recorrer sin for

for (let i = 0; i < precios.length; i++) {
    console.log(precios[i]);
}
precios.forEach((precio) => console.log(precio));
